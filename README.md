# 🚀 Ashish Singh — Space Engineering Portfolio

A fully custom personal portfolio website built as a single HTML file —
no frameworks, no build step, no dependencies.

**Vibe-coded with Claude — designed, built, and iterated in one session.**

🔗 **[Live site →](https://venomous68.github.io/ashish-portfolio/)**

---

## What's in it

A complete portfolio site for a space engineer, featuring:

- **Animated hero** — rotating orbital rings with satellite dots, starfield parallax background
- **Skills section** — categorised tech tags with shimmer hover effects
- **Timeline** — alternating left/right experience cards with animated entry
- **Project gallery** — cards with image lightbox and inline video playback (rover footage, sensor demos)
- **Certifications & contact** — clean section layout with hover link effects
- **Fully responsive** — collapses to single-column on mobile

## Tech

- Pure HTML + CSS + vanilla JavaScript
- Single `index.html` (~1200 lines) — entire site in one file
- Zero npm, zero build tooling, zero external JS dependencies
- Deployed via GitHub Pages

---

## How it was built

I had a clear idea of what I wanted — space aesthetic, project media front and centre,
timeline for experience — but no frontend background. I used Claude to generate the
initial structure, then iterated fast: tweaking the orbit animation, adding the video
lightbox, fixing mobile layout. The whole point was to ship something real quickly
and steer the output until it matched the vision. That's the workflow.
